This branch contains the non-AI CutFlow upgrade work. It is isolated from production so the existing live system is not changed while the upgrade is reviewed and tested.

Scope: dashboard, appointments, walk-in queue, customers, staff, services, payments, promotions, reports, branches, plus additive competitive-core database migrations for inventory, POS, memberships, vouchers, and outbound message queue support.
